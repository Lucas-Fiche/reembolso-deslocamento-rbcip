# Imagens do site (logo etc.)

Coloque aqui a **logo da RBCIP** para aparecer nos cabeçalhos.

## Como subir (pela web do GitHub)
1. Nesta pasta, clique em **Add file → Upload files**.
2. Arraste os arquivos com estes nomes:
   - `logo.png` — logo principal (PNG com fundo transparente, boa resolução).
   - `logo-branca.png` — *(opcional)* versão clara/branca, para usar sobre o
     cabeçalho azul.
3. Em "Commit changes", confirme.

Depois de subir, é só avisar que eu ligo a logo nas páginas.
